      Projet phare

      StickFlow v2.2.0

      ESSAYER ↗GitHub ↗

      Application d’animation de stickman par pivots, assistée par IA. Le principe : « l’IA assiste, l’utilisateur décide ».

      Fonctions IA

      • Fluidité : génère les images intermédiaires entre les images clés (linéaire, spline Catmull-Rom, ease-in-out).
      • Répétition : boucle fluide de la dernière image vers la première.

      Les images générées sont distinguées dans la timeline ; l’effet est non destructif.

      Éditeur complet

      • Timeline, pelure d’oignon, annuler / rétablir
      • Plusieurs personnages, coloration partielle
      • Calques de formes et de dessin, arrière-plans personnalisés
      • Formats 16:9, 9:16, 1:1, 4:5 · export GIF / PNG / MP4

      Technique

      TypeScript et Vite, rendu WebGL 2, PWA installable et hors ligne, déployée sur Cloudflare Workers. Tests Vitest, intégration continue GitHub Actions, décisions d’architecture documentées (ADR).

      • TypeScript
      • Vite
      • WebGL 2
      • PWA
      • Cloudflare Workers
      • Vitest
      • GitHub Actions
      • ADR
